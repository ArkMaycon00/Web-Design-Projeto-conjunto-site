# 💜 Colo — Cuidado para quem cuida

> Projeto desenvolvido para a disciplina de **Web Design**, unindo identidade visual, experiência do usuário (UX/UI) e desenvolvimento front-end.

---

## 📖 Sobre o Projeto

A **Colo** é uma plataforma acolhedora pensada para mães, pais e cuidadores. O objetivo do projeto é oferecer um espaço seguro de troca entre famílias e uma biblioteca de conteúdos confiáveis — sem julgamentos e sem o excesso de informações confusas da internet.

### ✨ Conceito Visual e UX/UI
* **Paleta Aconchegante:** Fugimos do "branco hospitalar" tradicional utilizando tons de **creme quente** (`#FAF6F0`), **lilás suave** (`#F3EDF7`), **roxo acolhedor** (`#6D398A`) e toques de **dourado** (`#F5A623`), transmitindo calma, empatia e conforto visual (inclusive para leituras noturnas).
* **Tipografia:** Combinação da fonte arredondada e amigável **Fredoka** nos títulos com **Inter** para máxima legibilidade nos textos.
* **Interatividade:** Barra de busca com animação dinâmica, filtros em tempo real por categoria, navegação por fases do bebê e botão interativo *"Te acolho"*.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estrutura semântica)
* **CSS3** (Variáveis CSS, Flexbox, Grid Layout, Glassmorphism e animações fluidas)
* **JavaScript Vanilla** (Filtros dinâmicos, efeito typewriter na busca e micro-interações)
* **Design Gráfico & Vetorial** (Identidade visual da marca Colo e ícones SVG)
